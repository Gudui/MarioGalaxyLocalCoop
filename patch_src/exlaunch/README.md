# GalaxyCoop ExLaunch Overlay

This directory contains the open-source ExLaunch module overlay (`subsdk9` + `config.json`) for **Super Mario Galaxy** (Nintendo Switch, Title ID `010099C022B96000`, version `1.0.0`).

Use `scripts/build.ps1` from the repository root to overlay this directory onto the pinned `vendor/exlaunch` checkout and build `subsdk9` and `main.npdm`.
