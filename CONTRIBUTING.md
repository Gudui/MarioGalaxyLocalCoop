# Contributing

Thank you for helping improve Super Mario Galaxy Local Co-op!

## Strict legal and privacy rules

Do **not** include, link to, or upload any of the following in issues, pull requests, or commits:

- Copyrighted Nintendo game binaries, ROMs, NSP/XCI files, `exefs` dumps, `romfs` archives, or extracted game assets.
- Console encryption keys, firmware files, prodinfo, or personal save files.
- Personal filesystem paths, usernames, or unredacted crash logs containing console identifiers.

## Pull requests

- Keep changes focused on open-source patch code, build/packaging scripts, or documentation.
- Verify that `.\scripts\build.ps1`, `.\scripts\package.ps1`, and `.\scripts\verify.ps1` pass cleanly before submitting.
